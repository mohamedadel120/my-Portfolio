# Breakthrough Energy Website - Inspiration & Implementation Ideas

## 🎯 **Key Design Elements from Breakthrough Energy**

### 1. **Animated Split Hero Text** ⭐ HIGH IMPACT
**What Breakthrough Does:**
- "Empowering innovators to build the future of energy"
- Text split across multiple lines with animation
- Each line animates separately
- Creates dynamic, engaging first impression

**Your Implementation:**
- Split hero title across lines:
  - "Building mobile apps"
  - "that go further"
  - "and connect users"
- Animate each line separately with stagger
- Use large typography (80-100px)

**Why It Works:**
- More engaging than single line
- Creates visual rhythm
- Professional, modern feel
