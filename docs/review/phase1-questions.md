# المرحلة 1: أسئلة المحتوى

ردّ بالعربي أو بالإنجليزي، في الشات أو اكتب تحت كل سؤال في الملف ده. لو سؤال مش عارف إجابته، سيبه
فاضي: الموقع مش هيعرض أي حاجة مش مؤكدة.

## أ. قرارات عامة

1. **الموقع لمين بالأساس؟**
   - شركات بتدوّر على مطور Flutter (وظيفة)
   - عملاء عايزين يعملوا تطبيق (فريلانس)
   - الاتنين بنفس الدرجة
2. **بتتكلم بـ "I" ولا "We"؟** (لو شغلك مع فريق أو شركة، "We" أدق في بعض المشاريع)
3. **تقييمات المتاجر:** عايز تعرضها؟ لو أيوه، اكتب التقييم الحالي لكل تطبيق من صفحته على المتجر.
4. **آراء العملاء (Testimonials):** هل الأربعة ناس حقيقيين ووافقوا إن كلامهم يتنشر؟ وجملة "reduced our
   app load time by 25%" نسيبها ولا نشيلها؟
5. **رقم واتساب ولينك حجز مكالمة** (Calendly أو غيره)، لو عايزهم في الموقع.

## ب. التطبيقات الناقصة

لكل تطبيق (هبعتلك قايمة باللي لقيته على جهازك عشان تأكد عليها):

- الاسم زي ما يظهر في المتجر
- لينك Google Play و/أو App Store (أو: لسه مانزلش / داخلي لشركة)
- 4 لـ 8 صور شاشة (أي صيغة، أنا هظبطها)
- جملة واحدة: التطبيق بيعمل إيه ولمين
- دورك فيه
- عدد التحميلات لو انت متأكد منه

## ج. قصص أقوى 4 أو 5 مشاريع

لكل مشروع 3 جمل قصيرة بس:

| المشروع | المشكلة (إيه اللي كان صعب أو ناقص قبل التطبيق) | دورك (عملت إيه انت بالظبط) | النتيجة (إيه اللي اتغير، حاجة تقدر تثبتها) |
|---|---|---|---|
| جملة | ✅ مكتوبة | | |
| ستوك | | | |
| البطل | | | |
| | | | |
| | | | |

**مثال:**
- **المشكلة:** المحلات اللي بتشتري وتبيع بالجملة كانت بتعد المخزون يدوي، فالأرقام بتغلط والطلب بيتأخر.
- **دوري:** بنيت التطبيق كامل بـ Flutter، من التصميم لحد النشر على المتجرين، وكنت مسؤول عن صيانته.
- **النتيجة:** وصل لأكتر من 10,000 تحميل على Google Play.
